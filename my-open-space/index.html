화면이 까맣고 오류도 안 뜬다
알갱이는 다 올라갔는데 SparkRenderer 를 장면에 안 넣은 것입니다. Spark 는 자체 렌더러를 scene.add() 해야 그립니다. 안 넣으면 조용히 아무것도 안 그리고 오류도 안 냅니다. 위 목록 둘째 줄을 보십시오.
공간이 거꾸로 서 있다
이 모델은 Y 가 아래를 향하고 three.js 는 Y 가 위입니다. 노트북에서 y 와 z 의 부호를 뒤집어야 바로 섭니다. 지금 확인하려면 위쪽 위아래 뒤집기 를 눌러 보십시오.
알갱이 개수는 나오는데 화면에 아무것도 없다
알갱이 덩어리는 일반 메시가 아니라서 Box3.setFromObject 가 빈 상자를 돌려줍니다. mesh.getBoundingBox() 로 재야 합니다.
Invalid file type 이 뜬다
확장자와 Spark 안쪽 이름이 다릅니다. .sog 의 안쪽 이름은 pcsogszip 입니다.
파일을 못 받는다
file:// 로 열면 브라우저가 파일 읽기를 막습니다. 같은 폴더에서 python -m http.server 를 띄우고 http://localhost:8000 으로 여십시오.
여기에 놓으면 그 파일로 다시 그립니다

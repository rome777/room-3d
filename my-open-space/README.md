## 도구 사이에서 걸린 것

`.spz` 는 크기는 재지지만 이 페이지에서 화면에 안 올라갑니다. 내 쪽 실수가 아니라
도구 두 개의 판이 어긋난 것이라, 확인한 내용을 그대로 적어 둡니다.

- splat-transform 3.4.2 가 쓰는 `.spz` 는 **판 4** 이고, gzip 없이 생으로 씁니다
  (파일 첫 네 바이트가 `NGSP`, 표준대로라면 gzip 이라 `1f 8b` 여야 합니다).
- Spark 2.1.0 은 gzip 을 먼저 기대해 `Invalid gzip header` 로 걸립니다.
  직접 gzip 으로 싸서 넣어 보면 그다음 관문에서 `Unsupported SPZ version: 4` 가 납니다.
- Spark 2.2.0 으로 올려도 같습니다. splat-transform 3.0.0 도 판 4 로 씁니다.
  splat-transform 에는 판을 고르는 옵션이 없습니다.
- 그래서 비교표의 `.spz` 칸은 파일 크기와 알갱이 개수로 채우고, 화면에 띄우는 것은
  `.sog` 를 씁니다. 알갱이 개수가 세 형식에서 같은지는 그대로 확인할 수 있습니다.
